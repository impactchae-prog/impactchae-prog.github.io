PRIVACY

개인정보처리방침

시행일: 2026년 11월 27일 · 개발·운영: impactchae-prog

바탕달력(Desktop Agenda)은 Windows 바탕화면에서 Google 캘린더 일정과 로컬 메모를 보여주는 앱입니다. 이 방침은 앱의 Google 연결, 로컬 보관, 이 안내 사이트에 적용됩니다.

1. 접근하는 Google 데이터와 권한

사용자가 Google 승인 화면에서 동의한 경우에만 다음 읽기 전용 권한을 사용합니다. Google 계정 비밀번호는 앱이 받거나 저장하지 않습니다.

  • calendar.calendarlist.readonly: 사용자가 접근할 수 있는 캘린더의 식별자, 이름, 색상 및 표시 상태를 가져와 선택 목록을 구성합니다. 캘린더 식별자에 이메일 주소가 포함될 수 있습니다.
  • calendar.events.readonly: 접근 가능한 캘린더의 일정 식별자, 제목, 시작·종료 일시 및 종일 여부를 읽습니다. 상세 설명, 참석자, 첨부 파일과 장소는 요청하거나 보관하지 않습니다.

동기화는 접근 가능한 캘린더들의 과거 2년부터 미래 1년까지의 일정을 가져옵니다. 앱의 캘린더 선택은 화면 표시 필터이며, 선택을 해제해도 해당 캘린더의 로컬 사본이 즉시 삭제되는 것은 아닙니다.

2. 사용 목적

받아온 데이터는 달력 표시, 검색, 날짜별 내용 확인, 오프라인 조회 및 사용자가 실행하는 내보내기·인쇄에 사용합니다. Google 원본 일정을 생성·변경·삭제하지 않습니다. 날짜 메모와 스티커 등 앱에서 작성한 내용은 로컬 데이터이며 Google 캘린더로 업로드하지 않습니다.

Google에서 받은 데이터는 광고, 판매, 신용 평가 또는 AI 모델 학습에 사용하지 않습니다. 바탕달력에서 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요건을 준수합니다.

3. 보관 위치와 보호

인증 및 API 통신은 사용자의 PC와 Google 사이에서 이루어집니다. 개발자가 운영하는 일정 저장 서버나 분석·광고 서버로 일정 및 인증 정보를 전송하지 않습니다.

기본 저장 위치는 해당 Windows 사용자의 %LOCALAPPDATA%\DesktopAgenda 폴더입니다. OAuth 갱신 토큰과 클라이언트 인증 정보는 Windows DPAPI의 현재 사용자 보호 기능으로 암호화해 저장합니다. 일정 사본과 로컬 메모 파일 자체는 암호화되지 않습니다. PC 접근 권한, 디스크 암호화 및 백업 보안은 사용 환경에 맞게 관리해야 합니다.

동기화가 성공하면 현재 일정 사본을 교체하며 복구용 이전 사본이 남을 수 있습니다. 앱을 사용하지 않거나 인터넷에 연결하지 않더라도 사본은 사용자가 삭제할 때까지 기기에 남습니다.

4. 내보내기, 백업과 제3자 제공

앱은 일정 데이터를 개발자에게 자동 전송하거나 제3자에게 판매하지 않습니다. 사용자가 내보내기·이미지 저장·인쇄를 실행하면 선택한 기간의 Google 일정이 결과물에 포함될 수 있습니다. 해당 파일 또는 인쇄물을 다른 사람이나 서비스에 전달할지는 사용자가 결정합니다.

앱의 로컬 백업에는 메모·스티커·설정과 캘린더 표시 설정에 사용한 식별자가 포함될 수 있습니다. Google 인증 정보와 Google 일정 사본 전체는 앱의 로컬 백업에 포함하지 않습니다. PC 전체 백업이나 별도 폴더 복사는 Google 사본까지 포함할 수 있습니다.

5. 연결 해제와 데이터 삭제

  1. Google 계정의 서드 파티 연결 관리에서 바탕달력의 접근 권한을 삭제하면 이후 Google 데이터 접근을 막을 수 있습니다. 이 조작으로 이미 기기에 저장된 사본까지 삭제되지는 않습니다.
  2. 로컬 Google 사본을 지우려면 앱을 종료한 뒤 위 저장 폴더의 google-session.json과 google-session.json.previous를 삭제합니다. 구버전 파일 google-auth.json, google-cache.json 및 각 .previous 파일이 있으면 함께 삭제합니다. 삭제 전 필요한 내용이 있는지 확인하세요.
  3. 메모·설정·자동 백업까지 모두 지우려면 앱을 종료하고 위 저장 폴더 전체를 삭제합니다. 별도로 내보내거나 백업한 파일은 사용자가 저장한 위치에서 따로 삭제해야 합니다. Google 원본 일정에는 영향을 주지 않습니다.

개발자는 사용자의 로컬 파일에 원격 접근할 수 없습니다. 앱을 다시 연결하면 사용자가 새로 허용한 Google 데이터가 다시 저장됩니다.

6. 안내 사이트와 문의

이 사이트는 GitHub Pages에서 제공하는 정적 페이지입니다. 별도의 회원가입, 일정 업로드, 광고, 자체 분석 스크립트 또는 추적 쿠키를 사용하지 않습니다. 호스팅 제공자인 GitHub는 사이트 제공·보안을 위한 접속 정보를 자체 개인정보처리방침에 따라 처리할 수 있습니다.

앱 및 개인정보 관련 문의는 개발자 문의 게시판에서 받습니다. 게시판은 공개되어 있으므로 일정, 학생 정보, 비밀번호, OAuth JSON 또는 토큰을 게시하지 마세요. 문의에 자발적으로 적은 내용은 문의 대응을 위해 사용됩니다.

7. 방침 변경

데이터 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. 기존 동의 범위를 벗어나는 Google 데이터 접근이 필요하면 변경 내용을 안내하고 Google 승인 절차를 다시 진행합니다.
